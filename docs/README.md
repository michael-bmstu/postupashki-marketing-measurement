## Как читать

1. Для запуска проекта — [корневой README](../README.md).
2. Для понимания целевого продукта — [продуктовый MVP](../agents_docs/PRODUCT.md), затем [план](../PLANS.md).
3. Для устройства текущей реализации — [архитектура](../agents_docs/ARCHITECTURE.md).
4. Для результатов исходного анализа — [результаты исследования](research-results.md) и [сводка пайплайна](../reports/summary.md).
5. Для изучения исследовательских вариантов измерения — [модель данных](marketing-data-model.md), [трекинг](telegram-tracking.md), затем [атрибуция](attribution-and-romi.md) и [эксперименты](incrementality-experiments.md). Эти материалы могут содержать предложения, которых ещё нет в коде.
6. Для планирования следующего запуска — [рекомендации по бюджету](marketing-budget-300k.md).
